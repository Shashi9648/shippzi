# Shippzi Website — React / TanStack Start

This is the full React source for the Shippzi landing page exported from Lovable.

## What's included

- TanStack Start v1 + Vite 7
- React 19 + TypeScript (strict)
- Tailwind CSS v4
- Framer Motion (`motion`) for animations
- Lucide icons
- Sonner toasts

## Required assets

Copy these image files into `src/assets/` before running:

| File | Used in |
|------|---------|
| `shippzi-logo.png` | Logo component |
| `hero-delivery.jpg` | Hero section |
| `ind-grocery.jpg` | Industries grid |
| `ind-pharmacy.jpg` | Industries grid |
| `ind-restaurant.jpg` | Industries grid |
| `ind-ecommerce.jpg` | Industries grid |
| `ind-courier.jpg` | Industries grid |
| `ind-retail.jpg` | Industries grid |

Also place a `favicon.ico` in the project root (or `public/`).

## Install & run

```bash
cd shippzi-code
bun install        # or npm install
bun dev            # or npm run dev
```

Open `http://localhost:8080`.

## Notes

- `routeTree.gen.ts` is auto-generated by TanStack Router. It will be created automatically when you run `bun dev` or `bun build`.
- The `Logo.tsx` imports the logo from `src/assets/shippzi-logo.png`. If your logo file has a different name or path, update that import.
